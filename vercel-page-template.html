🧭 Gmail CLI

Fast, secure command-line tool for Gmail, Calendar, Drive, and Docs.
Perfect for automation, scripts, and power users.

📧

Gmail

Send, search, and manage emails. Handle labels, filters, and drafts.

📅

Calendar

Create events, manage invitations, check availability.

📁

Drive

Upload, download, search, and organize files and folders.

📝

Docs

Create, edit, and export Google Docs documents.

Installation

Copy and paste this command in your terminal:

curl -fsSL https://yourdomain.com/install.sh | bash

Run this in PowerShell (as Administrator):

iwr https://yourdomain.com/install.ps1 | iex
Note: You may need to run PowerShell as Administrator for installation.

Quick Start

After installation, authenticate and start using:

# Authenticate with your Google account gog auth add your-email@gmail.com # List recent emails gog gmail list # Search emails gog gmail search "from:boss@company.com" # List calendar events gog calendar list # Upload a file to Drive gog drive upload document.pdf

Need help? Run gog --help
